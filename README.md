# cardiac-mri-qa

Uncertainty-aware analysis of cardiac MRI segmentation: how segmentation
error propagates into clinical indices (EDV / ESV / LVEF).

Status: repository initialised on 2026-09-28.

## Dataset

ACDC (Automated Cardiac Diagnosis Challenge), 150 patients, public release.
Citation: Bernard et al., IEEE TMI 37(11):2514-2525, 2018.

## Planned deliverables

- A reproducible nnU-Net baseline for short-axis cine MRI segmentation
- Error-propagation analysis from segmentation metrics to clinical indices
- An evaluation of uncertainty as a quality-control signal
